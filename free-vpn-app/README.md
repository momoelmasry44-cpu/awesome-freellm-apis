# 🛡️ Free VPN — تطبيق VPN مجاني وسهل

تطبيق VPN خاص بيك، بيشتغل على **Windows / Linux / macOS**، وبيوصلك بسيرفرات **مجانية** من مشروع
[VPN Gate](https://www.vpngate.net/) (مشروع أكاديمي من جامعة تسوكوبا في اليابان، سيرفراته بيشغلها متطوعين حوالين العالم).

## المميزات
- زرار واحد **اتصال / قطع الاتصال**
- اختيار الدولة، أو **أفضل سيرفر تلقائي**
- لو السيرفر مردش، التطبيق بيجرب سيرفر تاني لوحده
- بيعرض البنج والسرعة لكل سيرفر
- بيحفظ آخر قائمة سيرفرات عشان لو الموقع مش متاح
- مكتوب بـ Python فقط بدون مكتبات إضافية

## التثبيت والتشغيل

### 1) ثبّت OpenVPN (مرة واحدة بس)
- **Windows:** نزّل وثبّت OpenVPN من https://openvpn.net/community-downloads/
- **Linux:** `sudo apt install openvpn python3-tk`
- **macOS:** `brew install openvpn python-tk`

### 2) شغّل التطبيق
**الطريقة الأسهل على Windows (ملف exe):**
من تبويب **Actions** في الريبو ← `Build Free VPN (Windows exe)` ← آخر تشغيل ← نزّل `FreeVPN-windows`،
وشغّل `FreeVPN.exe` (هيطلب صلاحيات المسؤول تلقائيًا).

**أو باستخدام Python:**
```bash
# Windows (افتح CMD كمسؤول Administrator)
python free_vpn.py

# Linux / macOS
sudo python3 free_vpn.py
```

### من سطر الأوامر (بدون واجهة)
```bash
python3 free_vpn.py --list          # عرض السيرفرات
sudo python3 free_vpn.py --connect JP   # اتصال بسيرفر في اليابان (كود الدولة)
```

## ملاحظات مهمة
- السيرفرات مجانية وبيشغلها متطوعين، فالسرعة بتختلف، وممكن بعضها يفصل. لو حصل ده اضغط اتصال تاني أو غيّر الدولة.
- **الخصوصية:** مشغّلي سيرفرات VPN Gate ممكن يسجلوا الاتصالات (logs). استخدمه لتصفح عادي وفك الحجب، ومتعتمدش عليه في حاجات حساسة.
- لازم صلاحيات المسؤول عشان OpenVPN يقدر يعمل كارت الشبكة الافتراضي.
- استخدم الـ VPN بما يتوافق مع القوانين في بلدك.
