# 🛡️ Free VPN — تطبيق أندرويد (APK)

تطبيق VPN مجاني للموبايل، بيتصل بسيرفرات مجانية من مشروع [VPN Gate](https://www.vpngate.net/)
(مشروع أكاديمي من جامعة تسوكوبا في اليابان).

## التحميل
1. افتح صفحة **Releases** في الريبو على GitHub من الموبايل.
2. حمّل ملف `FreeVPN.apk` من آخر إصدار.
3. افتح الملف ووافق على "التثبيت من مصادر غير معروفة".
4. افتح التطبيق، ودوس على الزرار الكبير، ووافق على طلب الـ VPN.

## المميزات
- زرار واحد للاتصال وقطع الاتصال
- اختيار الدولة (مع علمها)، أو أفضل سيرفر تلقائي
- لو السيرفر مردش، التطبيق بيجرب سيرفر تاني لوحده
- بيعرض مدة الاتصال وكمية البيانات
- بيحفظ آخر قائمة سيرفرات

## ملاحظات
- السيرفرات مجانية وبيشغلها متطوعين، فالسرعة بتختلف. لو سيرفر بطيء غيّر الدولة.
- مشغّلي السيرفرات ممكن يسجلوا الاتصالات، فمتستخدموش في حاجات حساسة.

## البناء من الكود
بيتبني تلقائيًا بـ GitHub Actions (`.github/workflows/build-free-vpn-apk.yml`). أو يدويًا:
```bash
flutter pub get
flutter build apk --release
```
