# خطة الزيارات — تطبيق أندرويد

تطبيق بيعمل خطة زيارات أسبوعين في دبي: 17 حساب في اليوم، بأقل لف بالعربية.

## التثبيت
1. افتح صفحة الـ Release اسمها **visits-app-latest** في الريبو (أو Actions ← آخر run ← `visits-planner-apk`).
2. نزّل `visits-planner.apk` على الموبايل وافتحه (اسمح بالتثبيت من مصادر غير معروفة).
3. أي نسخة جديدة بتتثبت فوق القديمة من غير ما بياناتك تضيع.

## الاستخدام
- **الحسابات**: قوايمك من Google Maps متحمّلة جاهزة. دوس **📍 حدّد المواقع** مرة وانت على النت عشان التطبيق يجيب الإحداثيات الدقيقة من لينكات جوجل ماب (الـ CSV بتاع Takeout مافيهوش إحداثيات).
- تقدر تضيف/تعدل/توقف أي حساب، وتحط أهمية A/B/C و OTC.
- **⬇️ استيراد**: ملفات Google Takeout (CSV / JSON / KML) أو لصق أسماء ولينكات.
- **الخطة**: اختار أول اثنين ونقطة البداية (اختياري) ودوس "اعمل خطة الأسبوعين". كل يوم فيه الترتيب والميعاد وزرار يفتح الروت على جوجل ماب، وتقدر تصدّر Excel/CSV أو تشير الخطة.

## القواعد
- دبي بس. الاثنين–الجمعة، 17 حساب/يوم، أسبوعين.
- النهدي = 1، كل فرع كل أسبوع. ميدون = 1، كل الفروع مرة على الأقل.
- HealthHub = 3 (صيدلية + 2 دكتور)، الخميس والجمعة بس 1–3 الضهر، 3 فروع قريبين = 9 حسابات كل يوم.
- Med7 صيدلية = 1، عيادة = 2، من غير فرع النصري.
- أستر صيدلية = 1 للتكملة بس. مستبعد: عيادات أستر، صيدلية أستر جنب عيادة أستر، Pharm C.

## للمطورين
- الواجهة في `app/src/main/assets/www` (HTML/JS بدون مكتبات)، ومحرك التخطيط في `planner.js` (يشتغل في Node كمان).
- البناء بيحصل أوتوماتيك عن طريق GitHub Actions (`.github/workflows/visits-app.yml`).
- `app/visits.keystore` مفتاح توقيع شخصي ثابت (الباسورد في `app/build.gradle`) عشان التحديثات تتثبت فوق بعض.
